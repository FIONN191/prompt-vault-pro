# 桌面悬浮球与快速面板（1.0.9）

启动桌面版后，屏幕右侧显示独立置顶悬浮球，切换应用仍可使用。
点击打开快速录入和提示词搜索面板。复制后切回目标应用粘贴，不自动注入其他应用的输入框。

- 快速面板采用搜索优先布局，标签、关键词、收藏筛选可以组合；列表/网格可切换。点击「新增」展开快速录入，收起表单不会丢失草稿。
- 面板顶部可切换明暗主题，与主窗口和悬浮球同步；锁形按钮只固定面板，重新启动后默认允许拖动。
- 快速面板可自由拖动：按住顶部「快速提示词」标题或标题栏空白处移动，支持拖到其他显示器；关闭按钮仍可正常点击，输入框和列表不参与拖动。收起后再次打开，仍在悬浮球旁展开。
- 全局快捷键：Command/Ctrl+Shift+K 打开或收起，Esc 收起。
- 默认允许拖动：按住悬浮球左键移动，松手保存位置。拖动不会打开面板。
- 右键悬浮球或应用的“悬浮球”菜单中勾选“固定位置”后禁止拖动，仍可点击打开面板；取消勾选恢复拖动。固定时显示小锁角标。
- 位置和固定开关保存在应用用户目录的 floating-orb.json 中，退出并重新启动后恢复。
- 收起时保留未保存草稿；退出应用后草稿不保留。
- 关闭主窗口只隐藏窗口，悬浮球继续运行。
- 悬浮球右键菜单或应用的“悬浮球”菜单可打开主窗口、显示/隐藏悬浮球、退出。
- 隐藏后可通过全局快捷键恢复面板，或重新启动应用显示已有主窗口。
- 面板在悬浮球所在位置附近展开，靠近右边缘时向左展开。开关面板或切换应用不会重置悬浮球位置。
- 拖动时把球保持在显示器可用区域内；显示器移除或尺寸变化后，把超出可用范围的位置移回可见区域，即使已固定也可恢复可见。

主窗口保留原有 localStorage 作为唯一数据存储。面板不读写独立副本：通过受限 preload IPC 请求主窗口新增、复制，主窗口保存后广播快照。写入失败时不发布新状态，面板保留输入。

网页预览继续使用应用内面板，桌面置顶和全局快捷键只在 Electron 内可用。安装版与网页预览的数据仍通过 JSON 导出/导入搬迁。

验证：先 npm run build，然后使用已安装的 Playwright 运行 tests/desktop-smoke.cjs（可用 NODE_PATH 指定其位置）。脚本使用独立临时用户目录，验证置顶窗口、全局快捷键注册、macOS Finder 前台快捷键唤起、主窗口关闭后录入、系统剪贴板、最近使用、草稿保留、详情跳转、重新加载后的持久化及模拟写入失败。Windows 安装包可在 macOS 上交叉构建，但需在 Windows 真机验证运行行为。

拖动验证：macOS 上运行 tests/orb-drag-smoke.cjs。测试会使用 Swift/CoreGraphics 发送真实鼠标按下、移动和松开事件，验证拖动、固定/解锁、固定后点击、面板跟随、重启恢复、右键菜单勾选状态，以及屏幕外位置恢复。运行时会临时移动鼠标，结束后恢复原鼠标位置；使用独立临时配置，不修改实际素材库。设置 PROMPT_VAULT_TEST_EXECUTABLE 为打包应用的可执行文件路径，可对成品运行同样测试。
