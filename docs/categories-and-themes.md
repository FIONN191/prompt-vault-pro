# 自定义分类与主题 · v1.0.8

左侧分类列表上方提供常驻「+ 新增分类」入口，点击即可在侧栏输入名称，回车或点击「创建」立即保存并进入新分类，取消或 Escape 放弃草稿。空名称、同名分类和存储写入失败会在输入框下方提示；中文输入法选词时不会误提交。桌面侧栏与窄窗口抽屉均支持此入口。

左侧“管理分类”集中编辑分类名称、颜色、说明和排序，也可修改分类栏标题、全部入口和收藏入口的名称、显示数量。新增分类可用于完整编辑器、快速录入、详情、卡片、统计与搜索。名称独立于分类 ID，因此重命名不改变提示词归属。

分类移除时须选择迁移目标，保存后统一迁移提示词并删除分类定义。不能移除最后一个分类。取消管理窗口不会保存草稿。存储写入失败时保留编辑状态并提示，关联设置提交失败时回滚设置。

主题选择位于顶部导航：

- 简洁（默认）：深色灰阶，无背景网格、发光和装饰动画；自定义分类颜色保留在设置中。
- 浅色：中性白底与灰阶文字。
- 霓虹：保留原有色彩、网格和发光效果，显示分类自定义颜色。

桌面主窗口发布分类与主题设置，面板和悬浮球通过受限 IPC 同步。未设置过主题的已有安装也默认采用简洁模式。悬浮球拖动和固定位置设置继续由原独立配置维护。

新增偏好保存在 prompt_vault_pro_preferences_v1，原提示词存储键不变。首次加载会为旧提示词中的未知分类补充定义。备份格式升级为 version 2，同时导出 preferences。旧版数组和 version 1 JSON 继续兼容；默认导入只补充新分类，保留当前主题和已有分类属性。勾选“同时恢复备份中的分类属性、主题和分类栏名称”可恢复备份的设置与顺序，同时保留本地额外分类。
